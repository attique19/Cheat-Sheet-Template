HTML Cheat Sheet

  1. Basic Structure

    Every HTML page starts with this boilerplate structure.

    <!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>

  2. Headings

    HTML has 6 levels of headings, h1 being the largest.

    <h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

  3. Paragraphs and Text

    Basic tags for displaying and formatting text.

    <p>This is a paragraph.</p>
<strong>Bold text</strong>
<em>Italic text</em>
<u>Underlined text</u>
<br />  <!-- line break -->
<hr />  <!-- horizontal line -->

  4. Links

    Use anchor tags to link to other pages or websites.

    <!-- External link -->
<a href="https://google.com" target="_blank">Visit Google</a>

<!-- Internal link -->
<a href="about.html">About Page</a>

<!-- Link to section on same page -->
<a href="#contact">Go to Contact</a>

  5. Images

    Display images using the img tag. Always add alt for accessibility.

    <!-- Local image -->
<img src="photo.jpg" alt="My Photo" width="300" />

<!-- External image -->
<img src="https://example.com/image.png" alt="Example" />

  6. Lists

    Ordered lists are numbered, unordered lists use bullets.

    <!-- Unordered list -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- Ordered list -->
<ol>
  <li>First</li>
  <li>Second</li>
  <li>Third</li>
</ol>

  7. Tables

    Display data in rows and columns using table tags.

    <table>
  <thead>
    <tr>
      <th>Name</th>
      <th>Age</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Attique</td>
      <td>21</td>
    </tr>
  </tbody>
</table>

  8. Forms

    Collect input from the user using form elements.

    <form action="/submit" method="POST">
  <input type="text" placeholder="Your Name" />
  <input type="email" placeholder="Your Email" />
  <input type="password" placeholder="Password" />
  <input type="checkbox" /> Remember me
  <button type="submit">Submit</button>
</form>

  9. Div and Span

    div is a block container, span is an inline container for grouping elements.

    <!-- div takes full width (block) -->
<div class="card">
  <p>This is inside a div</p>
</div>

<!-- span stays inline -->
<p>My name is <span style="color: blue;">Attique</span></p>

  10. Semantic Elements

    Semantic tags give meaning to your HTML structure.

    <header>Site Header</header>
<nav>Navigation Links</nav>
<main>Main Content</main>
<section>A Section</section>
<article>An Article</article>
<aside>Sidebar Content</aside>
<footer>Site Footer</footer>

  11. Meta Tags

    Meta tags provide information about the page to browsers and search engines.

    <head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta name="description" content="JavaScript Cheat Sheet" />
  <meta name="author" content="Attique" />
  <title>My Page</title>
</head>

  12. Audio and Video

    Embed media files directly into your HTML page.

    <!-- Audio -->
<audio controls>
  <source src="audio.mp3" type="audio/mpeg" />
</audio>

<!-- Video -->
<video controls width="400">
  <source src="video.mp4" type="video/mp4" />
</video>

  13. iFrame

    Embed another webpage or content inside your page.

    <iframe
  src="https://www.google.com/maps/embed"
  width="600"
  height="400"
  allowfullscreen
></iframe>

  14. HTML Entities

    Use entities to display reserved or special characters.

    &lt;   → displays <
&gt;   → displays >
&amp;  → displays &
&copy; → displays ©
&nbsp; → non-breaking space
&quot; → displays "

  15. Input Types

    HTML supports many input types for different kinds of data.

    <input type="text" />
<input type="email" />
<input type="password" />
<input type="number" />
<input type="date" />
<input type="file" />
<input type="range" min="0" max="100" />
<input type="color" />
<input type="checkbox" />
<input type="radio" />

  16. Select Dropdown

    Let users pick an option from a dropdown list.

    <select name="language">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js" selected>JavaScript</option>
</select>

  17. Data Attributes

    Store custom data on HTML elements using data- attributes.

    <button data-id="101" data-role="admin">Click Me</button>

<script>
  const btn = document.querySelector("button");
  console.log(btn.dataset.id);   // 101
  console.log(btn.dataset.role); // admin
</script>

  18. Comments

    Comments are not displayed in the browser, used for notes in code.

    <!-- This is a single line comment -->

<!--
  This is a
  multi-line comment
-->

  19. Linking CSS and JS

    Connect your stylesheet and script files to the HTML page.

    <head>
  <!-- Link CSS file -->
  <link rel="stylesheet" href="style.css" />
</head>

<body>
  <!-- Link JS file at bottom of body -->
  <script src="script.js"></script>
</body>

  20. Favicon

    Add a small icon that appears on the browser tab.

    <head>
  <link rel="icon" type="image/png" href="favicon.png" />
</head>
