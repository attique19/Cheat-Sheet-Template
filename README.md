
# Cheat-Sheet-Template

A responsive web-based cheat sheet for JavaScript, HTML, and CSS, featuring practical code examples, syntax highlighting with Prism.js, and a clean, modern user interface.

## 🚀 Features

- **JavaScript Cheat Sheet:** Quick reference for JavaScript syntax, concepts, and code examples.
- **HTML Cheat Sheet:** Common HTML tags, elements, and attributes.
- **CSS Cheat Sheet:** CSS selectors, properties, layouts, and styling examples.
- **Syntax Highlighting:** Enhanced code readability using Prism.js.
- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Clean User Interface:** Simple and user-friendly navigation.
- **Practical Examples:** Easy-to-understand code snippets for quick learning.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Prism.js

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/attique19/Cheat-Sheet-Template.git
```

### 2. Navigate to the Project Folder

```bash
cd Cheat-Sheet-Template
```

### 3. Run the Project

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 🎯 Purpose

This project is designed to provide developers and students with a convenient reference for frequently used HTML, CSS, and JavaScript syntax.

It helps users quickly find code examples and understand essential web development concepts without searching through lengthy documentation.
